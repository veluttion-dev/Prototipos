OrderOrchestrator
@Service
orchestrator/OrderOrchestrator.kt
  • suspend processOrder(order)
    Public entry point. Creates CompensationManager, emits OrderCreated, delegates to runPipeline. Catches TimeoutCancellationException to trigger compensation; rethrows plain CancellationException.
  • suspend runPipeline(order, …)
    Orchestrates the full pipeline: parallel inventory check + fraud eval via async, then sequential reserve → charge, then fire-and-forget notification. Registers compensation lambdas after each irreversible step.
  • suspend handleFailure(order, …)
    compensation Runs all registered compensations via CompensationManager, updates status to FAILED, emits OrderFailed event.
CompensationManager
orchestrator/CompensationManager.kt
  • register(label, action: suspend () → Unit)
    Appends a compensation lambda to the actions stack. Called immediately after each irreversible step succeeds.
  • suspend compensate()
    compensation Executes all registered actions in reverse order inside a supervisorScope — one compensation failure never blocks the rest.
SimulatedInventoryService
@Service
inventory/SimulatedInventoryService.kt
  • suspend checkStock(items)
    Mutex Reads current stock levels. Throws InsufficientStockException if unavailable.
  • suspend reserve(orderId, items)
    Mutex Atomically decrements stock. Wraps decrement in withContext(Dispatchers.IO) to demonstrate IO dispatcher pattern.
  • suspend release(orderId, items)
    compensation always succeeds Restores reserved stock. Guaranteed reliable as a compensation action.
SimulatedPaymentService
@Service
payment/SimulatedPaymentService.kt
  • suspend charge(orderId, amount)
    Simulates payment processing with configurable failure rate. Throws PaymentFailedException on failure. Wrapped in withTimeout(5_000) by orchestrator.
  • suspend refund(paymentId)
    compensation always succeeds Reverses a charge. Guaranteed not to throw — compensations must be reliable.
SimulatedFraudService
@Service
fraud/SimulatedFraudService.kt
  • suspend evaluate(order)
    parallel Runs concurrently with checkStock via async. Returns FraudResult. Throws FraudDetectedException if flagged — cancels the sibling async via structured concurrency.
SimulatedNotificationService
@Service
notification/SimulatedNotificationService.kt
  • suspend send(orderId, event)
    fire-and-forget Launched via applicationScope.launch — not supervisorScope.

    Using supervisorScope { launch {} } would isolate failures but still suspend until the notification finishes, blocking the HTTP response. applicationScope.launch returns immediately. Failures are swallowed by a CoroutineExceptionHandler.
